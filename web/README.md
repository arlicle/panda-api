# Panda API Web Workbench

The React/TypeScript Web Workbench is planned for M4. M0 intentionally contains
no `package.json`, frontend dependency, generated asset, or runnable web UI.

The future application will consume versioned runtime DTOs rather than Rust
internal structs. See the [architecture baseline](../docs/2.0/01-architecture.md)
and [roadmap](../docs/2.0/07-roadmap.md).
